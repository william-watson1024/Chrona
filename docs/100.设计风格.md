
# 拾年 / CHRONA 设计风格

整体采用极简黑白风格，强调留白、秩序、时间感与克制感。

参考方向：

- Notion：黑白配色、信息层级清晰、低装饰、内容优先
- 喜茶：极简品牌感、大留白、黑白视觉、克制而高级
- Linear：简洁排版、细边框、低噪音界面
- Apple 系统应用：清晰层级、自然间距、功能优先

视觉规范：

- 主色：黑 `#111111`、白 `#FFFFFF`
- 辅助色：灰 `#666666`、浅灰 `#F5F5F5`
- 无渐变、少阴影、不过度圆角
- 中文使用简洁无衬线字体
- `CHRONA` 使用大写并增加字间距
- 布局保持大留白和低信息密度
- Todo 使用列表式排布，避免大量卡片
- 图标使用简洁线性风格
- 番茄钟页面以时间数字作为视觉中心
- 历史记录采用时间轴或日志式表达

核心原则：

> 像 Notion 一样克制，像喜茶一样有品牌感，界面只突出现在做什么、还剩多久、刚刚完成了什么。
