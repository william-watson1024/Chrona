# 拾年 / CHRONA UI 与交互规范

本文档只记录当前代码中已经形成的视觉和交互规则，面向后续页面开发和调整。当前页面主要由 `lib/theme/`、`lib/widgets/` 和 `lib/screens/` 实现。

## 1. 产品风格

CHRONA 当前采用：

```text
极简
黑白
克制
大留白
低信息密度
时间感
```

参考方向为 Notion、喜茶、Linear 和 Apple 系统应用，但最终以项目现有实现为准。

视觉原则：

- 白色作为主背景，黑色作为主文字和主要操作色。
- 使用黑 / 白 / 灰建立信息层级，不使用大面积彩色。
- 不使用渐变，不依赖阴影，不使用高装饰性的背景。
- 圆角只用于按钮、输入框、热力格和少量内容分组，避免把所有内容做成 Card。
- 列表内容优先使用底部分隔线，减少卡片边界。
- 图标优先使用 Material Icons，次级操作多使用 outlined 风格。
- 页面通过留白、字号和细分隔线建立层次，而不是通过复杂组件堆叠信息。

## 2. 当前颜色和基础视觉值

| 用途 | 当前值 | 使用位置 |
| --- | --- | --- |
| 主文字 / 主按钮 | `#111111` | 标题、主要文字、按钮背景、选中状态 |
| 白色背景 | `#FFFFFF` | Scaffold、底部导航、输入框 |
| 辅助文字 | `#858585` | 日期、说明、统计标签、次要信息 |
| 次辅助灰 | `#8B8B8B` | 计时页提示文字、部分状态文字 |

| 浅灰背景 | `#F0F0F0` / `#F1F1F1` / `#F6F6F6` / `#F8F8F8` | 计时环、图表背景、添加任务按钮、日记分组 |

- “拾 年”：31px、字间距 5、半粗体。
- “C H R O N A”：14px、字间距 3.1、中等字重。
- 品牌头部右侧使用 23px 的 `settings_outlined` 图标。

## 3. 页面结构和职责

```text
今朝 TodayScreen
├── 专注 Tab：日期任务、任务统计、开始专注
└── 日记 Tab：每日一问、回答、今日日记

记录 HistoryScreen
├── 周：7 天柱状统计
├── 月：按日热力格
└── 年：12 个月、每月 4 格年度概览

设置 SettingsScreen
├── 休息时长
├── 导出数据
└── 导入数据

专注计时页 FocusScreen
└── 本轮计时、暂停 / 继续、结束、通知提示

本轮记录页 FocusNoteScreen
└── 记录任务标题、实际时长和本轮笔记
```

记录页还可以进入：

- `DayDetailScreen`：某天的总时长、专注次数和记录列表。
- `RecordDetailScreen`：单条 FocusSession 的详情和笔记编辑。

底部导航固定包含三个入口：`今朝`、`记录`、`设置`。底部导航高度为 82px，上边使用 `#E9E9E9` 细分隔线；选中项使用黑色，未选中项使用 `#999999`。

## 4. 今朝页

### 4.1 页面头部

今朝页顶部依次为品牌头部、日期 / Tab 行和当天摘要：

```text
拾 年                         设置图标
C H R O N A

                          专注   日记
9月28日·星期一
3 已完成·2.50h 专注时长
```

日期可以点击打开日期选择器，也可以通过左右滑动日期分页切换。任务页和日记页使用同步的选中日期；回到前台时，如果原本浏览的是今天，会更新为新的本地日期。

日期业务格式为：

```text
M月D日 · 星期X
```

当前 `formatFocusDate()` 和今朝摘要的实际渲染为紧凑形式 `M月D日·星期X`，中点两侧没有空格；这是当前实现值，后续如需严格统一应单独调整格式化函数。

### 4.2 专注 / 日记 Tab

右侧使用文字 Tab，而不是胶囊式 `SegmentedButton`：

- 当前项为 `#111111`，字重 500。
- 未选中项为 `#858585`。
- 当前项底部有 2px 黑色细下划线。
- Tab 间距为 24px。
- 当前 Tab 只改变今朝内容区域，不改变底部导航选中项。

### 4.3 当天摘要

摘要显示当前选中日期的：

```text
已完成任务数 · 当天 FocusSession 实际专注时长
```

专注时长以两位小数小时显示，例如 `2.50h 专注时长`。摘要文字为 16px 灰色，可点击打开日期选择器。

### 4.4 Todo 列表

任务使用纵向列表，不使用大量 Card。每个任务行：

- 最小高度 94px，上下内边距 16px。
- 底部使用 `#E9E9E9` 分隔线。
- 左侧为 24px 圆形完成控件，未完成为灰色描边，完成后为黑色填充并显示白色勾。
- 标题 21px、中等字重，最多一行，超出省略。
- 专注时长使用 18px `schedule_outlined` 图标和 16px 灰色文字。
- 右侧提供删除图标和圆形开始按钮。
- 已完成任务标题使用删除线、降低透明度，并禁用开始专注按钮。

任务行支持：

- 点击内容进入任务详情。
- 点击完成控件切换完成状态。
- 点击删除图标后确认删除。
- 拖动调整同一日期内的排序。
- 点击播放按钮开始专注。

“添加任务”使用低噪音按钮：整行高度 68px、`#F6F6F6` 背景、10px 圆角、加号图标和 17px 文字，不使用黑色主按钮样式。

## 5. 专注视图

### 5.1 专注计时页

`FocusScreen` 以时间数字为视觉中心：

- 页面左右内边距 24px，顶部内容从 12px 开始。
- 任务标题居中，31px、中等字重。
- 有任务备注时在标题下方显示 `notes_outlined` 图标和 20px 灰色备注。
- 中央计时环尺寸 306×306px，环宽 9px。
- 计时数字 70px、细字重。
- 状态文字显示“专注中”“已暂停”“已完成”或“已结束”，22px 灰色。
- 点击计时环只切换剩余时间 / 已经过时间的显示方式，不改变计时状态。

主要操作使用黑底白字的 `PrimaryButton`：高度 68px、10px 圆角、20px 中等字重。运行中按钮为“暂停”，暂停后为“继续”。

专注页还提供：

- “结束专注”：先弹出“提前结束本轮专注？”确认框。
- 计时结束后的“停止提醒”。
- 底部的震动提醒说明。
- 返回按钮和底部导航。

### 5.2 休息视图

休息与专注共用计时页，但：

- 标题为“休息一下”。
- 计时环上方显示“短休息”。
- 结束后显示“准备开始下一轮”和“开始专注”。
- 休息中提供“跳过休息”，不显示专注的“结束专注”确认流程。
- 底部提示为“休息结束后将响铃并震动”。

### 5.3 本轮记录页

本轮记录页用于把一次已结束的内存计时转成持久化记录：

- 顶部标题为“本轮记录”。
- 正常结束显示“本轮专注完成”，提前结束显示“本轮专注结束”。
- 任务标题可编辑，使用无边框 30px 输入样式。
- 下方显示开始时间、结束时间和实际时长。
- 提前结束额外显示“提前结束”。
- 记录输入框标题为“这段时间做了什么？”，最小 8 行，边框圆角 10px。
- 底部主按钮为“保存”，沿用黑底白字 `PrimaryButton`。
- 保存过程中禁用重复保存；失败时在按钮上方显示错误文字。

## 6. 日记视图

日记 Tab 包含两个浅灰内容分组，而不是多个复杂卡片：

```text
每日一问
├── 问题文本
├── 编辑问题图标
└── 问题回答输入框

今日日记
└── 日记正文输入框

去年今日
保存
```

规则：

- “每日一问”使用太阳图标；修改问题只显示简洁的 `edit_outlined` 图标，不显示“换一个”文字。
- 问题文本 18px、黑色、中等字重，行高约 1.55。
- 问题回答最多 500 字，最多 4 行。
- 今日日记正文最多 1000 字，最多 5 行。
- 输入框白底、边框 `#E1E1E1`、圆角 9px。
- 两个内容分组背景为 `#F8F8F8`，圆角 11px，内部使用 16px 左右内边距。
- “去年今日”使用历史图标和低强调文字按钮。
- 日记保存按钮全宽、高度 54px、8px 圆角、18px 中等字重。
- 保存成功通过 SnackBar 提示“已保存”，保存失败提示重试。

## 7. 记录页

### 7.1 周 / 月 / 年切换

记录页顶部使用左右箭头和中间的下拉菜单切换时间粒度：

- `周`：按周一至周日显示。
- `月`：按月份显示。
- `年`：按年份显示。
- 左右箭头分别移动上一周期 / 下一周期。
- 切换粒度时，周期锚点重置为当前日期。
- 从年度视图点击某个月进入对应月视图。

当前周期的实际标题由代码显示为 `周`、`月`、`年`，下方显示真实范围：

- 周：`M月D日 - M月D日`
- 月：`YYYY年M月`
- 年：`YYYY年`

当前实现没有显示“本周 / 本月 / 本年”字样；当前周期和历史周期都通过实际日期范围区分。

### 7.2 统计摘要

统计区域使用紧凑的三列布局，列之间用 1px 浅灰竖线分隔：

```text
0.00h        0        0.00h
专注时长     专注次数   日均时长 / 月均时长
```

- 数值 20px、黑色、中等字重。
- 标签 13px、灰色。
- 时长统一按两位小数小时显示。
- 当前没有“最长一天”统计。

### 7.3 周视图

- 显示周一至周日 7 根柱状图。
- 每根柱对应当天 `actualDurationSeconds`。
- 背景柱为浅灰，实际时长为黑色。
- 柱状图固定按 8 小时作为满刻度，超过满刻度时封顶显示。
- 点击某天进入日详情页。

### 7.4 月视图

- 显示当月日历网格，每天一个热力格。
- 热力格颜色按当月每日实际专注时长的相对值分成 0～4 级灰阶。
- 当前选中日期使用黑色边框标识。
- 点击日期会筛选当前页面下方的该日记录列表。
- 页面底部显示“少 → 多”的 5 级热力图例。

### 7.5 年视图

- 展示 12 个月，按 4 行 × 3 列排列。
- 每个月固定显示 4 个热力格：1–7 日、8–14 日、15–21 日、22 日至月底。
- 这是年度概览，不是完整的月历。
- 点击月份切换到该月视图。

### 7.6 记录列表和空状态

- 记录按日期分组，组内按开始时间倒序。
- 日分组标题使用“今天”“昨天”或 `M月D日`。
- 每组显示专注次数和总时长。
- 单条记录不使用 Card，使用上下 18px 留白和底部分隔线。
- 记录标题 20px；时间和笔记为灰色 16～17px；右侧显示时长。
- `CANCELLED` 记录的时长后显示“提前结束”。
- 空状态使用 88×88px 图像、24px“暂无记录”标题和 16px辅助说明。

## 8. 设置页

设置页继续使用品牌头部，但隐藏右上角设置按钮；页面标题“设置”为 38px、黑色、半粗体。

当前设置和数据操作：

- “休息时长”：20px 标签，右侧无下划线 Dropdown，选项为 5 / 10 / 15 / 20 / 30 分钟。
- “数据”分组标题为 20px。
- 导出数据 / 导入数据使用列表行，不使用 Card；每行上下 15px，底部有分隔线。
- 数据操作图标 22px，标题 17px，说明 13px，右侧为 chevron 图标。
- 导入或导出过程中整行降低透明度并禁用点击。

## 9. 公共设计规则

### 字号层级

当前页面没有集中式字号 Token，实际使用的主要层级如下：

| 层级 | 常见字号 | 用途 |
| --- | --- | --- |
| 超大页面 / 日期标题 | 36～38px | 设置标题、今朝日期 |
| 计时数字 | 70px | 番茄钟中心数字 |
| 页面内容标题 | 30～34px | 任务标题、本轮记录标题 |
| 列表主文字 | 20～21px | 任务、历史记录标题 |
| 区块标题 / 重要说明 | 18～22px | 日记标题、统计标题 |
| 辅助信息 | 13～17px | 日期、说明、时长、标签 |

后续新增页面优先复用现有字号层级，不要为单个元素引入新的字号档位。

### 间距和布局

- 页面主内容常用左右内边距 24px。
- 滚动页面常用顶部 12px、底部 28～40px。
- 重要区块之间常用 24～72px 的大留白。
- 内容列表优先使用垂直留白和分隔线，不用密集卡片。
- 底部导航必须为页面内容预留安全区和底部 padding。

### 按钮和输入框

- 通用主按钮：高度 68px、黑底白字、10px 圆角、20px 文字。
- 日记保存按钮：高度 54px、黑底白字、8px 圆角、18px 文字。
- 低强调操作使用 TextButton 或浅灰背景按钮，不使用额外阴影。
- 任务详情页优先使用底部线输入样式。
- 多行日记和专注记录使用浅色边框输入框，聚焦时边框变为黑色。
- 保存 / 导入 / 删除等有数据影响的操作，在当前代码中使用 SnackBar 或 AlertDialog 提供反馈和确认。

### 图标、空状态和导航

- 优先使用 Material Icons；删除、设置、编辑、历史、播放等已有语义应复用现有图标。
- 次级图标通常为 18～23px，页面返回和周期箭头可到 28～30px。
- 空状态保持居中、低密度，提供一条明确下一步提示。
- 底部导航只保留 `今朝 / 记录 / 设置` 三项，不新增胶囊式标签或复杂导航层级。
