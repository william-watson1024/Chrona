# 技术栈

- Flutter + Dart
- Android 优先，后续兼容 iOS
- UI：Material 3
- 状态管理：Provider
- 本地数据库：SQLite + sqflite
- 本地配置：shared_preferences
- 通知与震动：flutter_local_notifications
- 时间处理：timezone
- 架构：简单分层，Screen → Provider → Service/Database
- 不使用后端、登录、云同步、Firebase、复杂状态管理或 Clean Architecture
- 目标：先完成可运行、可打包 APK 的基础工程
