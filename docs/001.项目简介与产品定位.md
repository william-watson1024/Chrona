# 拾年 / CHRONA 项目简介与产品定位

## 项目定位

CHRONA 是一款本地优先的极简效率记录应用：

```text
Todo + 番茄钟 + 时间记录 + 日记
```

它不只记录“准备做什么”，也记录一段时间最终花在了哪里，以及这段时间完成了什么。

## 当前主要能力

- Todo：按日期创建、编辑、排序、完成和删除任务。
- 番茄专注：基于真实结束时间的倒计时，支持暂停、继续、提前结束和休息模式。
- 每轮专注记录：保存实际时长、任务标题快照、状态和本轮笔记。
- 专注历史与统计：按周、月、年查看 FocusSession 和时长统计。
- 每日一问：按日期保存问题、回答和问题文本。
- 日记：每天保存一条日记内容，并支持修改。
- 本地数据备份与恢复：以 JSON 文件导出和覆盖恢复任务、专注记录、日记及休息时长设置。

## 产品特点

- 完全本地运行。
- 无登录。
- 无后端。
- 无云同步。
- Android 优先。
- 极简黑白视觉和低信息密度布局。

## 名称

英文名：

```text
CHRONA
```

名称来源于与时间相关的 `chrono-`，表达时间记录、积累和回望。
