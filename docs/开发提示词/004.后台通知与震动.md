
# 拾年 / CHRONA — M4 后台通知与震动

请在现有 Flutter 项目中，实现番茄钟到点后的后台通知与震动提醒。

技术栈保持：

- Flutter + Dart
- flutter_local_notifications
- timezone
- 复用现有 Provider、FocusScreen、Theme 和导航
- 不新增无必要依赖

## 目标

实现：

```text
开始番茄钟
→ 根据 endsAt 注册本地通知
→ App 可切后台 / 锁屏
→ 时间到
→ 手机震动
→ 不播放声音
→ 显示通知
→ 用户可停止提醒
```

本阶段重点是“到点提醒可靠”，不实现 FocusSession 持久化。

## 一、通知设计

创建专用通知 Channel，例如：

```text
chrona_focus
```

要求：

- 声音关闭
- 震动开启
- 高优先级
- 仅用于番茄钟完成提醒

通知内容示例：

```text
专注完成

阅读 Orca 论文
本轮 25 分钟已结束
```

提供操作按钮：

```text
[停止提醒]
```

点击通知主体：

```text
→ 打开 CHRONA
→ 回到本轮完成 / 记录相关页面
```

## 二、调度原则

不要依赖 Flutter Timer 负责后台提醒。

真实提醒时间必须基于：

```text
endsAt
```

开始专注时：

```text
scheduleNotification(endsAt)
```

暂停时：

```text
cancelNotification()
```

继续时：

```text
重新计算 endsAt
→ 重新注册通知
```

提前结束时：

```text
cancelNotification()
```

确保旧通知不会误触发。

## 三、Android 权限

正确处理：

- Android 13+ 通知权限
- Android 12+ 精确定时相关能力
- 不要假设所有设备默认允许精确提醒

如果当前插件支持 exact alarm 能力，优先复用插件已有接口。

不要自己重复造 Android 原生桥接，除非插件确实无法完成。

## 四、震动

时间到后：

- 只震动
- 不播放声音
- 前台 / 后台 / 锁屏都要尽量可用

优先通过：

```text
flutter_local_notifications
```

已有能力实现。

不要为了震动额外引入新的插件，除非确实无法满足需求。

## 五、停止提醒

用户必须能停止提醒。

可靠方式：

```text
通知操作按钮：[停止提醒]
```

App 前台时也提供：

```text
[停止提醒]
```

如果项目已经具备可复用的震动控制能力，则直接复用。

暂时不要实现复杂的全局音量键监听。

不要引入：

```text
AccessibilityService
高权限监听
自定义后台常驻 Service
```

## 六、前后台一致性

需要处理以下场景：

```text
前台运行
后台运行
锁屏
重新打开 App
```

如果用户回到 App 时已经超过：

```text
endsAt
```

则：

```text
remaining = 0
status = finished
```

UI 状态与通知状态必须一致。

不要出现：

```text
通知说完成
但 App 还在倒计时
```

## 七、开发测试模式

保留：

```text
10 秒
30 秒
1 分钟
25 分钟
```

用于快速测试。

重点测试：

```text
10 秒
```

这样可以快速验证通知、震动和状态切换。

## 八、代码结构

优先复用现有工程。

如果需要，可以新增：

```text
lib/services/notification_service.dart
```

职责仅包括：

```text
initialize()
requestPermission()
scheduleFocusEnd()
cancelFocusEnd()
```

不要继续拆成：

```text
NotificationRepository
NotificationRepositoryImpl
ScheduleNotificationUseCase
NotificationMapper
```

保持简单。

## 九、本阶段不要实现

```text
❌ FocusSession SQLite 持久化
❌ 历史记录真实数据
❌ 统计
❌ 云同步
❌ 登录
❌ 音量键全局监听
❌ 自定义 Android 后台常驻 Service
❌ WorkManager
```

## 十、验收标准

完成后必须满足：

```text
1. 10 秒番茄钟能正常触发提醒
2. App 前台时正常震动
3. App 后台时正常震动
4. 手机锁屏时能收到提醒
5. 不播放提示音
6. 暂停后旧通知被取消
7. 继续后按新的 endsAt 提醒
8. 提前结束后不会再收到旧通知
9. 点击通知可以打开 App
10. 点击“停止提醒”可以结束提醒
11. 回到 App 后计时状态与通知状态一致
```

## 十一、开发原则

优先级：

```text
复用现有能力
> Flutter / 插件官方能力
> 已有依赖
> 新增实现
```

特别注意：

- 尽量使用已有中间件和插件能力
- 不重复造轮子
- 不自行重写已有通知/调度能力
- 不大规模重构现有项目
- 不修改与 M4 无关的代码

完成后只告诉我：

1. 修改了哪些文件
2. 通知如何调度
3. 暂停 / 继续如何取消和重新调度
4. Android 权限如何处理
5. 如何逐项验证上述验收标准

不要继续实现下一阶段 FocusSession 持久化。
