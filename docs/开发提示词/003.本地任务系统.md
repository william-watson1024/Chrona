
# 拾年 / CHRONA — M2 本地任务系统

请在现有 Flutter 项目中，把首页 Todo 从 Mock 数据升级为真实的本地任务系统。

技术栈保持：

- Flutter + Dart
- Provider
- SQLite + sqflite
- path
- 不新增无必要依赖

## 目标

实现：

```text
添加任务
→ SQLite 持久化
→ Provider 更新状态
→ 首页自动刷新
→ 完成 / 取消完成
→ 删除任务
→ 点击 ▶ 进入专注页
```

App 重启后任务仍然存在。

## 数据模型

Task：

```text
id
title
note
completed
createdAt
completedAt
```

SQLite：

```sql
CREATE TABLE task (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    title TEXT NOT NULL,
    note TEXT,
    completed INTEGER NOT NULL DEFAULT 0,
    created_at INTEGER NOT NULL,
    completed_at INTEGER
);
```

可以预留 `focus_session` 表，但本阶段不要实现其业务逻辑。

## 目录建议

```text
lib/
├── models/
│   └── task.dart
├── database/
│   └── app_database.dart
├── providers/
│   └── task_provider.dart
└── screens/
    └── today/
```

优先复用现有项目结构，不要为了匹配目录而大规模重构。

## TaskProvider

只需要：

```text
loadTasks()
addTask()
toggleTask()
deleteTask()
```

数据流：

```text
TodayScreen
→ TaskProvider
→ AppDatabase
→ SQLite
```

不要引入：

```text
Repository
RepositoryImpl
UseCase
DTO
Mapper
Clean Architecture
```

除非当前项目已经有这些结构，应优先复用已有实现。

## 页面行为

添加任务：

```text
标题：必填
备注：可选
```

标题为空时禁止保存。

任务操作：

```text
点击 ○
→ 标记完成

点击 ✓
→ 恢复未完成

删除
→ 弹出确认框

点击 ▶
→ 将当前 Task 传入 FocusScreen
```

删除确认：

```text
删除「阅读 Orca 论文」？

[取消] [删除]
```

## 排序

首页：

```text
未完成任务
↓
已完成任务
```

组内按照：

```text
createdAt DESC
```

新任务优先显示。

## 首页统计

将：

```text
已完成
```

改为根据真实 Task 数据计算。

专注时长暂时保持 Mock 或显示 `0`，不要提前实现 FocusSession。

## 开发原则

优先级：

```text
复用现有代码
> Flutter 官方组件
> 已有依赖
> 新增实现
```

要求：

- 优先复用现有 Theme、Widget、Dialog、底部导航
- 不重复造轮子
- 不大规模重构已有 UI
- 不修改与本功能无关的代码
- 保持代码简单，可读

## 本阶段不要实现

```text
震动

FocusSession 写入
专注统计
标签
项目
优先级
截止日期
子任务
搜索
云同步
登录
```

## 验收标准

完成后必须满足：

```text
1. 可以新增任务
2. 标题不能为空
3. 可以完成 / 取消完成
4. 可以删除任务
5. 首页状态即时更新
6. 点击 ▶ 能把正确 Task 传给专注页
7. 杀掉 App 再打开，任务仍然存在
```

完成后只告诉我：

1. 修改了哪些文件
2. SQLite 表结构
3. Provider 的职责
4. 哪些现有组件被复用了
5. 如何逐项验证上述验收标准

不要继续实现下一阶段番茄钟功能。
