
# 拾年 / CHRONA 核心页面 UI 实现

请基于当前已有的 Flutter 项目和「拾年 / CHRONA」首页视觉风格，实现以下三个页面：

1. 专注计时页
2. 本轮记录页
3. 历史记录页

当前阶段只完成 UI、Mock 数据和基础页面跳转，不实现真实业务逻辑。

---

## 一、开发原则

优先级：

```text
复用现有能力
> Flutter 官方组件
> 已安装依赖
> 成熟第三方组件
> 自己实现
```

特别注意：

- 先检查项目中已有的 Widget、Theme、底部导航、字体、间距、颜色等
- 能复用现有组件就不要重新写
- Flutter / Material 3 已有组件能实现的，不自己造轮子
- 已有成熟 package 能解决的问题，不重新实现底层组件
- 不重复创建类似的按钮、导航栏、标题栏
- 只有至少两个页面都会使用的 UI 才考虑抽公共 Widget
- 不为了“架构漂亮”过度封装

不要引入：

- 新状态管理框架
- 新路由框架
- Clean Architecture
- Repository / UseCase 等业务层
- SQLite
- 通知
- 震动
- AlarmManager
- 后台任务

---

# 二、整体视觉

严格延续现有首页。

参考：

- Notion：内容优先、黑白、低装饰
- 喜茶：品牌感、大留白
- Linear：细线、克制
- Apple：清晰的信息层级

设计原则：

```text
白色背景
黑色主文字
灰色辅助文字
浅灰分隔线
大留白
少圆角
基本无阴影
无渐变
无彩色
```

不要自行加入彩色进度条、渐变、玻璃拟态或大面积卡片。

# 三、页面 1：专注计时

建议：

```text
lib/screens/focus/focus_screen.dart
```

布局参考设计图。

顶部：

```text
←                              设置图标

          阅读 Orca 论文
          继续看 Section 3
```

中间为整个页面视觉核心：

```text
       圆形进度环

          24:37
          专注中
```

要求：

- 圆环使用细线
- 未完成部分浅灰
- 已完成部分黑色
- 时间数字尺寸明显大于其他文字
- 不要加入复杂动画

底部操作：

```text
[           暂停           ]

          结束专注

ⓘ 时间结束后将通过震动提醒
```

底部继续复用项目现有导航：

```text
今天    记录    设置
```

当前仍选中「今天」。

### 当前阶段交互

使用 Mock 状态即可。

点击：

```text
暂停
```

切换为：

```text
继续
```

点击「结束专注」可以直接进入「本轮记录页」。

倒计时数字可以写死：

```text
24:37
```

不要实现真实 Timer。

# 五、页面 3：历史记录

建议：

```text
lib/screens/history/history_screen.dart
```

顶部复用首页品牌区域：

```text
拾 年
C H R O N A
```

右上角设置图标。

标题：

```text
记录
```

按照日期分组。

例如：

```text
今天
9月27日 · 星期六

20:00 — 20:25   |   阅读 Orca 论文
                    看完 Introduction 和 Section 2

18:30 — 18:55   |   写 RagForge
                    完成 DocumentService 设计

14:00 — 14:25   |   整理笔记
                    整理 SGLang 阅读笔记
```

然后：

```text
昨天
9月26日 · 星期五
```

继续展示历史。

布局重点：

- 左边展示时间
- 中间使用细灰色竖线
- 右边展示任务标题与记录内容
- 不使用 Card
- 日期之间通过大留白区分
- 记录之间使用浅灰分隔线

底部导航：

```text
今天    记录    设置
```

当前「记录」为选中状态。

# 六、组件复用

请先检查现有代码。

已有的以下内容必须优先复用：

```text
App Theme
颜色
文字样式
底部导航
品牌 Header
通用按钮
间距规范
图标风格
```

如果不存在，可以抽取少量公共组件，例如：

```text
BrandHeader
ChronaBottomNavigation
PrimaryButton
```

但不要为了单次使用的内容建立 Widget 文件。

原则：

```text
出现一次 → 页面内部实现

重复两次以上
且结构基本一致
→ 再考虑提取组件
```

# 七、图标

优先使用：

```text
Material Symbols / Material Icons
```

例如：

```text
arrow_back
settings_outlined
home_outlined
bar_chart
person_outline
info_outline
pause
play_arrow
```

不要为了简单图标：

- 自己画 SVG
- 自己画 Canvas
- 下载图片
- 添加新的 icon package

如果项目已经有图标库，则优先复用已有库。

- 修改了哪些文件
- 新增了哪些公共 Widget
- 哪些地方复用了现有组件
