# 拾年 / CHRONA 功能范围与信息架构

本文档描述当前已经存在的页面、入口和业务范围。详细流程分别见 [`004.核心业务流程.md`](./004.核心业务流程.md) 和 [`005.番茄钟状态机.md`](./005.番茄钟状态机.md)。

## 1. 底部导航

```text
今朝
记录
设置
```

公共底部导航由 `ChronaBottomNavigation` 提供：

- 今朝：进入任务和日记主界面。
- 记录：进入 FocusSession 历史和统计。
- 设置：进入休息时长、结束提醒方式、导入和导出。

## 2. 今朝

```text
今朝
├── 专注
│   ├── 当前日期任务
│   ├── 添加任务
│   ├── 编辑任务
│   ├── 完成 / 取消完成
│   ├── 删除任务
│   └── 开始番茄钟
│
└── 日记
    ├── 每日一问
    ├── 问题回答
    ├── 今日日记
    ├── 去年今日
    └── 保存 / 修改
```

### 2.1 顶部摘要

当前选中日期、完成任务数和当天实际专注时长显示在今朝页头部：

```text
9月28日·星期一
3 已完成·2.50h 专注时长
```

日期支持点击选择、左右滑动切换；任务页和日记页共用并同步选中日期。当前日期格式化函数实际输出为中点两侧无空格的紧凑形式，详细 UI 约定见 [`006.UI与交互规范.md`](./006.UI与交互规范.md)。

### 2.2 专注 Tab

任务使用列表布局，支持：

- 添加任务并指定备注、计划日期和专注时长。
- 编辑标题、备注和专注时长。
- 完成 / 取消完成。
- 删除任务。
- 拖动调整同一天的排序。
- 从未完成任务开始专注。

### 2.3 日记 Tab

日记页按当前日期加载 `JournalEntry`，包含每日一问、回答、今日日记和保存按钮。每天最多保存一条日记；同一天再次保存时更新原记录。

## 3. 专注流程

```text
任务
→ 开始专注
→ 基于 endsAt 倒计时
→ 暂停 / 继续
→ 正常结束或提前结束
→ 本地通知 / 震动提醒
→ 填写本轮完成内容
→ 保存 FocusSession
```

专注保存后的分支：

- 正常完成：保存 `COMPLETED` FocusSession，进入休息计时。
- 提前结束：保存 `CANCELLED` FocusSession，进入记录页。

休息模式使用同一个计时器，但不会生成 FocusSession；休息完成后由用户手动开始下一轮专注。通知和状态细节见 [`005.番茄钟状态机.md`](./005.番茄钟状态机.md)。

## 4. 记录

```text
记录
├── 周
├── 月
└── 年
```

### 周

- 以周一至周日为一个周期。
- 显示每天专注时长柱状图。
- 显示周期总时长、专注次数和日均时长。
- 下面按日期分组显示 FocusSession 列表。
- 点击某天进入日详情。

### 月

- 显示当月每天一个灰阶热力格。
- 显示当月总时长、专注次数和日均时长。
- 点击某天筛选该日的 FocusSession 列表。

### 年

- 显示 12 个月的年度灰阶热力概览。
- 每个月固定 4 个时间段：1–7 日、8–14 日、15–21 日、22 日至月底。
- 显示全年总时长、专注次数和月均时长。
- 点击月份进入对应月视图。

左右按钮支持浏览其他周、月和年。统计数据来自当前已加载的 FocusSession，不使用单独的统计表。

## 5. 设置

当前设置页实际包含：

- 休息时长：5、10、15、20、30 分钟，保存在 `SharedPreferences`。
- 提醒方式：响铃、震动、响铃并震动，应用于专注和休息结束提醒，保存在 `SharedPreferences`。
- 导出数据：生成 JSON 备份文件。
- 导入数据：选择 JSON，确认后覆盖恢复任务、专注记录和日记，并恢复休息时长及提醒方式设置。

通知权限在应用启动和开始安排计时时通过通知服务处理；专注和休息结束提醒共用设置中的声音 / 震动方式。

## 6. 专注和记录相关页面

```text
FocusScreen
└── 专注 / 休息倒计时、暂停、继续、结束和提醒操作

FocusNoteScreen
└── 编辑本轮任务标题、填写本轮笔记、保存 FocusSession

DayDetailScreen
└── 某一天的总时长、次数和专注记录

RecordDetailScreen
└── 单条 FocusSession 详情和笔记编辑
```

## 7. 当前功能边界

当前产品不包含：

- 登录和账号体系。
- 云同步和服务端数据。
- 社交功能。
- 项目管理、标签、子任务和团队协作。
- AI 自动生成任务、问题或日记内容。
- App 进程被杀死后的活动番茄钟自动恢复。
